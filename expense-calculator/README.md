# Java Expense Calculator

A command-line Java program that asks for a budget and a list of expenses.
It adds the expenses and tells you whether you are within, over, or exactly on budget.
Enter all amounts as whole numbers in pence.

## How to run

With JDK 17 installed, run these commands from the project folder:

```bash
javac Hello.java
java Hello
```

## Example

Enter a budget of 2000 pence and two expenses of 500 and 800 pence.
The total is 1300 pence, leaving 700 pence in the budget.
